# 📝 考研英语（一）大作文 · 填空成文与智能批改（鲁述钊 / 王晶婷 / DeepSeek 三套体系）

选年份 → 看真题题目（中英对照）→ 三段填空成文 → 20 分制评分 + DeepSeek AI 实时点评。

## ✨ 功能

- **17 年真题全覆盖**（2010–2026 英语一 Section III Part B，20 分），**三套三段模板并行**：
  - **鲁述钊体系**：长难句＋倒装；第二段 For one thing / In the meantime … For another ＋ 名人事例；
    第三段 结论＋建议＋`Only in this way`
  - **王晶婷体系**：第一段 9 种总体描述＋细节＋图文字；第二段主旨句＋十大万能原因（选 2–3）；
    第三段 总结＋六大建议＋展望
  - **DeepSeek 体系**：本项目 **AI 原创模板**（不取任何讲义，可自由使用）
    一眼抓住画面 → 一句点透寓意 → 两条原因＋一个例子 → 一条落地建议＋`Only in this way` 收尾，
    句长居中、衔接最紧
- **题目区直接用真题原题，中英文对照**：
  - 左栏「英文原题」：真题原文；右栏「中文对照」：中文翻译
  - 下方「图画/图表内容」：原卷是图片，这里给出可直接写进作文的画面说明
  - 「💡 看本题标准主旨句」：**默认折叠**，先自己写，卡壳再点开
- **三段式填空**（严格按大作文结构）：
  - 第一段：总体描述 → 细节/对比 → 图文字
  - 第二段：点透寓意（主旨句）→ 原因总起 → 原因一 → 原因二 →（可选）具体例子
  - 第三段：结论 → 落地建议 → 展望收尾
  - 每段候选句型三层：本段指定 → 同类其他句型 → 同段落其他小节的通用句型
- **选项不再固定死**：
  - 讲义里 `A / B / C` 二选一写法在构建时拆成独立句型
  - 每段槽位下方是**推荐替换词条**，点一下即用
  - 主旨句槽位有 **「💡 用本题主旨句」** 一键填入本年标准主旨句
  - 每段都有 **🤖 AI 帮我想 3 句**（按真题原题＋本题寓意＋你已填好的信息生成）
  - 下拉框还有 **✍️ 自己写（自由输入）**
- **任何段都能删、也都能恢复**：每小节「🗑 删除本段」、每句「🗑 删除这句」（主句也能删）；
  删掉标「已删」变灰、成文里不出现，点「↩ 恢复默认」原样回来；删段按"本段不计入"处理
- **版式真实还原**：三段齐头式（顶格、段间空行）、不写标题不写落款；
  预览可开「👁 格式标记」看每段词数与句数；「📄 复制全文」「💾 下载 TXT」
- **🔍 语法与用法逐条纠正（离线，83 条规则）**：冠词、主谓一致、动词形式、介词搭配、名词单复数、
  句式结构、中式表达、标点大小写、流水句，另加大作文专项（number/amount 主谓一致、图画时态、
  误写标题落款、段首缩进）；每条给"原文 → 应写成 → 中文原因"，可一键复制修改清单
- **20 分制评分，扣分明细全部公开**：
  - 内容 7 / 结构 5 / 语言 6 / 格式 2（对应 0.35 / 0.25 / 0.30 / 0.10）
  - 核心判分点：**第二段是否点出本题寓意**（与标准主旨句做关键词比对）
  - 语言分从基线 3.9 往上挣；每处语法硬伤 −0.30；**模板化上限** 4.5/6.0
  - 结果页列出"语言分是怎么算出来的"每一步
- **🤖 AI 智能评价（DeepSeek）**：逐句纠错、重新打分定档、亮点提炼、高分升级句式；
  并给出**规则评分 vs AI 评分对照**与差值原因

## 🚀 使用方式

1. 双击 `考研英语大作文写作.html`（本地使用，除 AI 功能外无需联网）
2. 首页选年份 → 写作页可随时切换体系 → 三段填空 → 规则评分 / AI 智能评价
3. 用 AI 评价或 AI 造句需填一次 DeepSeek API Key（点「🔑 AI 设置」），Key 只存在你自己的浏览器

## 📚 句型库清洗说明

原语料库 `sentence_bank.json` 共 237 条，其中 194 条由 PDF 按页自动抽取，
含大量断行碎片（如 `fundamental economic basis for doing sth.`、`brought to our attention.`）。
本软件在构建时做了清洗：丢弃 152 条无法成句的碎片、把 `sth. / xx / ___` 改成规范槽位、
把 `A / B / C` 二选一写法拆成独立句型。
最终保留 **134 条可用句型**（鲁述钊 19 + 王晶婷 84 + DeepSeek 31）。
