# 📝 考研英语（一）大作文 · 填空成文与智能批改（5 套模板 × 6 种风格）

选年份 → 看真题题目（中英对照）→ 选模板填空成文 → 20 分制评分 + DeepSeek AI 实时点评。

> **这一版按用户反馈重做了骨架**：模板与风格**彻底分离** ——
> **5 套模板定骨架**（按题型自动配）、**6 种风格定措辞**（随时切换），
> 每段有段预算、每个槽位有字数上限，**全篇硬上限 210 词（含你自己补写的句子）**。

## ✨ 功能

### 一、5 套体裁分离的模板（来自语料库 v2）

| 模板 | 适用题型 | 必写词数 | 全开词数 |
|---|---|---|---|
| 图画·哲理品质类 `V2_PIC_QUALITY` | 图画题（品质/励志） | 143 | 179 |
| 图画·社会现象类 `V2_PIC_PHENOMENON` | 图画题（现象/问题） | 143 | 179 |
| 图表·趋势型 `V2_CHART_TREND` | 图表题（变化趋势） | 146 | 169 |
| 图表·占比/对比型 `V2_CHART_PROPORTION` | 图表题（比例构成） | 146 | 169 |
| 文字材料作文 `V2_TEXT` | 文字/引语题 | 101 | 124 |

- **按 `genre` 自动配模板**：17 年真题里图画 14 年、图表 3 年（2024/2025/2026），不会串味
- 每套 9～10 个小节，**每个小节都有段预算**（如「本段 17/22 词」），超出标红
- 图画题候选池里**不会**出现图表句，图表题候选池里**不会**出现 `The drawing…`（软件侧做了三道体检）

### 二、6 种选句风格（骨架不变，只换句子）

`不限` / `鲁述钊` / `王晶婷` / `Monkey`（全心全意·边明锐）/ `周思成` / `DeepSeek`

- 点一下风格按钮，**同一套模板里自动换成该老师的句子**，段落数和每段功能不变
- 你**手动选过的段落会被锁住**，不会被风格切换覆盖（避免辛苦填的槽位被冲掉）
- 该套模板里没有这个风格的候选句时，会提示"已保持原句，换「全部」看所有风格"
- **DeepSeek 风格是本项目 AI 原创**（31 句），不取自任何讲义

### 三、字数预算：这才是"不超字数"的关键

```
总词数 = 模板固定句词数 + Σ(每个槽位实际填词)
硬上限 = 210 词（含学生自己写的句子）
```

- **顶部总预算条**：实时显示「预计总词数 N / 210 词」，超过 88% 转橙、超过 210 转红
- **段头段预算**：「本段 12/18 词」，超出 1.6 倍标红
- **槽位字数上限**：每个输入框右侧实时计数「3/8 词」（`thesis≤12`、`caption≤8`、`topic≤4`…），超限标红
- **字数不足会告诉你差多少**：「当前 138 词，离 160 词底线还差 22 词：模板必写 146 词，剩下的要靠你自己写」

### 四、17 年真题全覆盖（2010–2026 英语一 Part B，20 分）

- **17 年真题图画全部内嵌**（取自语料库 `images/`，用户提供原卷截图，点击可放大）
- 2025（耐用消费品）、2026（老年护理机器人）另配**数据对照表**，直接抄数值
- **题目区中英对照**：左栏英文原题、右栏中文翻译、下方"图画/图表内容"一句话概括
- **「💡 看本题标准主旨句」默认折叠**：先自己写，卡壳再点开

### 五、填空成文与编辑

- 三段式：描述 → 议论 → 结论建议；每段多小节，每小节可加句
- 每小节 **🗑 删除本段**、每句 **🗑 删除这句**（主句也能删），删了能 **↩ 恢复默认**
- 下拉框除模板句外还有 **✍️ 自己写（自由输入）** 和 **🤖 AI 帮我想 3 句**
- 槽位下方是**推荐词条**，点一下即用；主旨句槽位有 **「💡 用本题主旨句」**
- **参考答案**：一键填出 160–210 词的完整示范（模板句 + 逐题真实数据 + 1–2 句自己的话）

### 六、评分与批改

- **20 分制**：内容 6.5+ / 7 · 结构 5 · 语言 6 · 格式 2，扣分明细全部公开
- 核心判分点：**第二段是否点出本题寓意**（与本题主旨句做关键词比对）
- **格式 2 分**按 210 词硬上限判：超限直接扣分；段落词数失衡也扣分
- **🔍 语法与用法逐条纠正**（离线 84 条规则）：冠词、主谓一致、动词形式、介词搭配、
  名词单复数、句式结构、中式表达、标点大小写、流水句、大数读法、政府加 the 等
- **🤖 AI 智能评价（DeepSeek）**：逐句纠错、重新定档、亮点提炼、高分升级句式，
  并给出"规则评分 vs AI 评分"对照

## 🚀 使用方式

1. 双击 `考研英语大作文写作.html`（本地使用，除 AI 功能外无需联网）
2. 首页选年份 → 写作页顶部可随时切风格 → 三段填空 → 规则评分 / AI 智能评价
3. 用 AI 评价或 AI 造句需填一次 DeepSeek API Key（点「🔑 AI 设置」），Key 只存在你自己的浏览器
